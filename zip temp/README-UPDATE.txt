JOHN BROWN — CONTENT UPDATE
===========================

Copy the contents of this ZIP into the ROOT of your existing MiddleSchoolHistory repository.
Allow the changed HTML/CSS/reference files and the three new portraits to merge into place.

IMPORTANT: This is intentionally a small update package. It does NOT contain your existing
John Brown navigation icons, other content images, UI stickers, or font file, so it will not
overwrite the finalized versions you already placed in the site.

The package expects quick_facts.png and vocabulary.png to already be present in:
/assets/images/ui/
