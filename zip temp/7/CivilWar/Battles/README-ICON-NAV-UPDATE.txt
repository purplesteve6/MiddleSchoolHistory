CIVIL WAR BATTLES — ICON NAVIGATION UPDATE
==========================================

This update replaces the text battle strip with the supplied battle icons.

Behavior
--------
- Active battle: full-color icon.
- Inactive Union victories: blue-tinted icon.
- Inactive Confederate victories: gray-tinted icon.
- Hampton Roads: split blue/gray treatment because the battle was inconclusive.
- Overview retains a compact text button because there is no separate Overview icon.
- The horizontal battle strip remains sticky while the student scrolls the page.
- Hovering the strip and using a mouse wheel scrolls the battle icons horizontally.
- The scrollbar is custom-styled to match the Civil War blue/gray theme.
- Previous/Next controls at the bottom now use the corresponding full-color battle icons.

Assets
------
The supplied 1254×1254 PNG icons were converted to compact, alpha-preserving WEBP files for the website. The original PNG files are not repackaged.

Update-package rule
-------------------
Only files edited or newly created for this update are included.
