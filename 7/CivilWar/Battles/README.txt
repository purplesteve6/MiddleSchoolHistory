DESIGN
------
• Union victories use a Union-blue page accent.
• Confederate victories use a Confederate-gray page accent.
• Hampton Roads uses a split blue/gray treatment because the ironclad duel was inconclusive.
• The Wilderness/Spotsylvania page uses blue because the combined page emphasizes Grant's strategic continuation of the Overland Campaign, while explicitly stating that the individual battles were inconclusive.
