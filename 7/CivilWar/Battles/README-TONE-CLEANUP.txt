CIVIL WAR BATTLES — NARRATIVE TONE CLEANUP
=========================================

This update removes teacher-facing / student-referential narration from the battle pages.

Examples removed or rewritten include:
- “helps students see...”
- “students should remember...”
- “for middle school students...”
- “this page needs to...”
- “this is a good page for showing...”

The historical point is now stated directly instead of talking about how the reader should learn it.

Only the 12 battle HTML files and this update note are included.
