MIDDLE SCHOOL HISTORY — SITE FEATURES & STICKERS
=================================================

PURPOSE
-------
Keep this file in the MAIN REPOSITORY ROOT and include it whenever the repo is shared for future website work.
Before inventing a new callout style, check this list for an existing reusable option.

GENERAL ASSET RULES
-------------------
• Sticker/logo graphics live in: /assets/images/ui/
• Sticker files are PNG unless noted otherwise.
• Normal historical/content images should preferably be WEBP.
• When a sticker already contains its own title words, DO NOT repeat those same title words as text beside or below it.
• A distinct subtitle is okay when useful (example: Big Question sticker + “Final Reflection”).
• Keep sticker graphics responsive and preserve their aspect ratio.

CURRENT STICKER / CALLOUT GRAPHICS
----------------------------------
1. BIG IDEA
   File: /assets/images/ui/bigidea.png
   Use for: The central takeaway, thesis, or essential understanding for a page/section.
   Existing examples: Greek Mythology, Western Hemisphere, John Brown.

2. DID YOU KNOW?
   File: /assets/images/ui/didyouknow.png
   Use for: Memorable, surprising, unusual, or high-interest facts.
   Important: Do not add a second “Did You Know?” text heading. The graphic is the heading.

3. 60 SECONDS WITH...
   File: /assets/images/ui/sixty_seconds_with.png
   Use for: A very fast overview of a person, place, civilization, event, concept, etc.
   Suggested contents: 4–6 short facts in cards/tiles.
   The subject name may appear separately below the sticker (example: “John Brown”).

4. BIG QUESTION
   File: /assets/images/ui/big_question.png
   Use for: Open-ended historical thinking questions, lesson framing questions, reflection prompts, or debate questions.
   Optional subtitle examples: “Final Reflection,” “Turning Point,” “Think Like a Historian.”

5. DECISION POINT
   File: /assets/images/ui/decision_point.png
   Use for: Interactive or hypothetical historical choices where the student chooses between actions and then learns what actually happened.
   Good pattern: Give context → offer 2–3 choices → reveal historical outcome/explanation.
   Important: Do not repeat “Decision Point” as a text heading when the sticker is displayed.

6. PRIMARY SOURCE
   File: /assets/images/ui/primary_source.png
   Use for: Direct quotations, letters, speeches, laws, newspaper excerpts, diary entries, photographs/documents being analyzed, etc.
   Pair with: source/date note and brief context.
   Important: Do not repeat “Primary Source” as a text heading when the sticker is displayed.

7. TO HELP YOU REMEMBER
   File: /assets/images/ui/helpremember.png
   Use for: Mnemonic devices, memory tricks, acronyms, rhymes, associations, visual cues, and other simple ways to help students remember important facts or sequences.
   Good pattern: Show the memory device prominently, then briefly explain what each part helps the student recall.
   Important: Do not repeat “To Help You Remember” as a text heading when the sticker is displayed.

8. QUICK QUIZ
   File: /assets/images/ui/quickquiz.png
   Use for: Short knowledge checks embedded within or at the end of a page.
   Suggested format: 1–5 concise questions, usually multiple-choice or another quickly answerable format, with immediate feedback when practical.
   Use it to reinforce material just taught rather than introduce new information.
   Important: Do not repeat “Quick Quiz” as a text heading when the sticker is displayed.

9. QUICK FACTS
   File: /assets/images/ui/quick_facts.png
   Use for: Compact grids or collections of short, highly scannable facts about a person, place, event, or topic.
   Good pattern: Place the sticker above a 3–6 tile fact grid.
   Important: Do not repeat “Quick Facts” as a visible text heading when the sticker is displayed.
   Existing example: John Brown Home page.

10. VOCABULARY
   File: /assets/images/ui/vocabulary.png
   Use for: A dedicated vocabulary/reference section that collects important terms and definitions in one place.
   Pair with: vocabWord hover definitions inside the reading when useful.
   Important: Do not repeat “Vocabulary” as a visible text heading when the sticker is displayed.
   Existing example: John Brown Home page.

11. COLORING BOOK
    File: /assets/images/ui/coloring-book.png
    Use for: Callouts that link students to a related page in the site's Coloring Book game.
    Good pattern: Pair the sticker with a small coloring-page thumbnail, a short title, and a clear link such as “Open the coloring page →”.
    Important: The sticker can serve as the visual label for the callout; do not add a redundant “Coloring Book” heading unless the layout specifically needs text for accessibility or clarity.
    Existing example: Civil War → War at a Glance → Appomattox surrender callout.

12. PERSON OF INTEREST
    File: /assets/images/ui/person-of-interest.png
    Use for: Short biographical callouts that introduce a historical person directly relevant to the surrounding event or topic.
    Good pattern: Small centered Person of Interest sticker → portrait → person's name → concise context explaining why the person matters here.
    Portrait rule: Preserve the supplied portrait ratio (500 × 640, or 25:32) and show the full portrait without cropping.
    Sticker sizing: Keep the sticker modest—about 75% of the portrait width, centered above the portrait.
    Important: The sticker already contains “Person of Interest,” so do not repeat those words as a text heading.
    Existing example: Civil War → Key Battles person callouts.

13. KEY TAKEAWAY
    File: /assets/images/ui/key-takeaway.png
    Use for: The single most important fact, connection, or memory-worthy idea a student should retain from a page.
    Good pattern: Use once in a consistent location near the top of a content page, after the main hero/at-a-glance material and before the detailed reading.
    Writing rule: Keep the accompanying takeaway to one short, plain-language statement. It should answer: “If a 7th grader remembers only one thing from this page, what should it be?”
    Important: The sticker already contains its own wording, so do not add a redundant “Key Takeaway” text heading.
    Existing example: Civil War → Battles → each individual battle page.

REUSABLE SITE FEATURES / INTERACTIONS
-------------------------------------
1. VOCABULARY HOVER DEFINITIONS
   Pattern: <span class="vocabWord" data-def="Definition here.">term</span>
   Use for important academic/history vocabulary without interrupting the reading flow.

2. CLICKABLE / EXPANDING TIMELINE
   Use for sequences where students click events to reveal more information.
   Existing John Brown example: Bleeding Kansas escalation timeline.

3. 36-HOUR / EVENT-SEQUENCE INTERACTIVE
   Use for a short, tightly ordered event where timing matters.
   Existing John Brown example: Harpers Ferry raid sequence.

4. DECISION INTERACTIVE
   Use with the Decision Point sticker.
   Students select an option; JavaScript reveals the historical choice/outcome and explanation.
   Existing John Brown example: Frederick Douglass deciding whether to join Brown at Harpers Ferry.

5. INTERACTIVE INTERPRETATION / EVIDENCE CARDS
   Use for competing historical interpretations.
   Students click a label/position to reveal evidence supporting that viewpoint.
   Existing John Brown example: Freedom Fighter / Martyr / Murderer / Dangerous Radical.

6. ROUTE / JOURNEY DIAGRAM
   Use for migrations, escapes, expeditions, trade routes, military movements, etc.
   Can be a simple HTML/CSS sequence or a custom map/SVG when geography is important.
   Existing John Brown example: Missouri-to-Canada liberation route.

7. QUICK-FACT TILE GRID
   Use for short biographical/event facts that scan quickly.
   Use the Quick Facts sticker when the grid is a standalone named section.
   Works especially well inside “60 Seconds With...” sections.

8. CHAPTER / TOPIC PAGE NAVIGATION
   Multi-page topics can use a horizontal/stacking chapter-nav row plus previous/next page buttons.
   Existing John Brown example: Home → Bleeding Kansas → Missouri Liberation → Allies & Arguments → Harpers Ferry → Trial & Legacy.

9. PRIMARY-SOURCE DOCUMENT PANEL
   Parchment/document-style box for quotations or source excerpts.
   Use the Primary Source sticker at the top instead of a duplicate text label.

10. QUICK QUIZ / KNOWLEDGE CHECK
   Use with the Quick Quiz sticker for a brief embedded check for understanding.
   Can be static or interactive; if interactive, give immediate, age-appropriate feedback.
   Keep it short enough that it feels like a break in the reading rather than a separate assessment.

11. MEMORY AID / MNEMONIC CALLOUT
   Use with the To Help You Remember sticker.
   Appropriate for mnemonics, acronyms, rhymes, memorable comparisons, chunking strategies, and other recall aids.
   The memory device should be accurate and simpler to remember than the facts it is teaching.

12. COLORING BOOK CALLOUT
    Use with the Coloring Book sticker when a topic has a related coloring page.
    Recommended pattern: small page thumbnail + Coloring Book sticker + page title + direct link to the coloring-book viewer.
    Keep the callout compact so it supplements the history content rather than taking over the section.
    Existing example: Civil War → War at a Glance → Grant & Lee at Appomattox.

13. KEY TAKEAWAY CALLOUT
    Use with the Key Takeaway sticker to isolate the one essential memory from a page.
    Keep it concise and consistent; it is not a replacement for the Big Idea feature, which can carry a broader interpretation or thesis.
    Existing example: Civil War → Battles individual battle pages.

DESIGN / CONSISTENCY NOTES
--------------------------
• Normal body copy should follow the established site/topic body font unless a topic intentionally specifies otherwise.
• Decorative/display fonts are okay for major topic titles when appropriate.
• Existing global header/footer partials should be reused rather than recreated locally.
• Avoid generic CSS selectors that accidentally alter shared header/footer elements.
• Topic-specific CSS should stay scoped whenever practical.
• Build pages for middle-school readability: short sections, strong hierarchy, visuals, vocabulary help, and interactive breaks.

ADDING A NEW STICKER OR FEATURE
-------------------------------
Whenever a new reusable sticker, callout, interaction, or page pattern is created:
1. Add its asset to /assets/images/ui/ if applicable.
2. Add its exact filename and intended use to this file.
3. Note any special behavior (no repeated text, interactive JS requirement, sizing, etc.).
4. Mention at least one page that uses it once it has been implemented.
